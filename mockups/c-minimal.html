Opinionated enough to ship

Most classless sheets are either too plain to use or too heavy to justify. fertig aims at the gap between them.

Bidirectional

Logical properties throughout, so dir="rtl" mirrors the entire sheet rather than patching it.

Classless

Semantic tags are styled directly. Seven optional classes exist if you want them; you can ignore every one.

Modern only

OKLCH, light-dark(), cascade layers, anchor positioning, container queries. Nothing left over.

Accessible

Every colour pair clears WCAG AA in both themes, measured rather than assumed.
