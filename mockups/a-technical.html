What it does

Bidirectional

Logical properties throughout, so dir="rtl" mirrors the entire sheet. Persian and Arabic get the same layout, not a patched one.

Classless

Semantic tags are styled directly. Seven optional classes and a handful of layout utilities exist if you want them; you can ignore every one.

Modern only

OKLCH, light-dark(), cascade layers, anchor positioning, container queries. Nothing carried for browsers that are already gone.

Accessible

Every colour pair clears WCAG AA in both themes, measured rather than assumed. Components answer to ARIA, not to classes.
