Why another classless sheet

Most are either too plain to ship or too heavy to justify. fertig aims at the gap: opinionated enough to look finished, small enough that you never think about it again.

Bidirectional

Written in logical properties throughout, so dir="rtl" mirrors the whole sheet — Persian and Arabic get the same layout, not a patched one.

tested in both directions

    Questions

    Before you link it

    Does it really need no classes?

    None. Seven exist if you want them, and a page that uses zero of them still looks finished.

    How do I override something?

    Write ordinary CSS. The sheet sits in its own cascade layers, so anything unlayered beats it at any specificity — no !important, ever, on either side.

    What about older browsers?

    The baseline is Chrome 125, Safari 17.5 and Firefox 129. Everything newer sits behind @supports and is additive, so nothing breaks when it is missing.

    Can I change the colours?

    Set --ac. Where contrast-color() exists, the text on top corrects itself automatically.
